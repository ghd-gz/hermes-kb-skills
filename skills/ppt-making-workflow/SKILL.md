# PPT制作应用

## 工作流（8步 + 可选视频导出）

### Step 1：需求对齐 + 模板选择

**第一部分：需求对齐** — 确认受众/场景/时长/素材/约束。

**第二部分：展示模板选项** — 让用户从以下库中选2-3个：

| 库 | 来源 | 数量 |
|:---|:-----|:-----|
| **库A：归藏 PPT** | guizang-ppt-skill | 双风格（杂志风+瑞士风） |
| **库B：HTML PPT Studio** | open source | 36主题+15成品Deck |

### Step 2：内容组织

- **分类表达**，不是时间线叙事
- 每类先提30-50字核心摘要 → **等用户确认** → 再展开为300字

### Step 3：逐页规划

查表达模型映射，确定每页布局和图表类型。

| 布局 | 用途 | 内容量 |
|------|------|--------|
| S01 Cover | 封面 | 标题+副标 |
| S02/S03 | 目录/论点 | 3-5要点 |
| S05/S10 | 左右对比 | 两栏 |
| S06 | 数据指标 | 3-4数字 |
| S07 | 流程管道 | 4-6步 |
| S21 | 网格展示 | 4-6卡片 |
| S22 | 结语 | 宣言+3条 |

### Step 4-5：HTML骨架搭建 + 内容填充

```bash
cp guizang-ppt-skill/assets/template-swiss.html ./index.html
```

**方案选择：**
- ≤15页 → subagent委托
- ≥15页/数据密集型 → Python build脚本

### Step 6：质量门自检

| 检查项 | 通过标准 |
|:------|:---------|
| 内容完整 | 所有数字/人名/百分比都在 |
| 字号达标 | 全部≥10px |
| 配色一致 | 仅一套主题色 |
| 布局多样 | 不超2/3同layout |
| 无残留 | 无"待建/已移除"痕迹 |

### Step 7：交付

1. 选转PDF
2. **上传飞书云盘**（必做）
3. 自动归档案例
4. 发送文件到对话窗口
5. 交付简报

### Step 8：视频导出（可选）

如果用户想录音做视频，走 `web-video-presentation` skill。
